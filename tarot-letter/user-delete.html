계정 및 데이터 삭제 요청

타로 레터 (Tarot Letter) — Just Init

1. 앱 내에서 직접 삭제하기

가장 빠른 방법입니다. 앱에서 바로 계정을 삭제할 수 있습니다.

  1. 타로 레터 앱을 열고 로그인합니다.
  2. 홈 화면 우측 상단의 설정(⚙️) 아이콘을 탭합니다.
  3. 화면 하단 계정 섹션에서 "회원 탈퇴"를 탭합니다.
  4. 안내 메시지를 확인한 후 "탈퇴하기"를 탭합니다.
  5. 보안을 위해 본인 확인(Apple/Google 재인증)이 진행됩니다.
  6. 완료되면 모든 데이터가 삭제되고 로그인 화면으로 이동합니다.

2. 이메일로 삭제 요청하기

앱에 접근할 수 없는 경우, 아래 이메일로 삭제를 요청할 수 있습니다.

이메일: justinit.service@gmail.com

요청 시 아래 정보를 포함해 주세요:

  • 제목: 계정 삭제 요청
  • 가입에 사용한 소셜 계정 정보 (Apple 또는 Google 이메일)
  • 앱에 등록된 닉네임 (기억나는 경우)

요청 접수 후 영업일 기준 3일 이내에 처리되며, 완료 시 이메일로 안내드립니다.

3. 삭제되는 데이터

계정 삭제 시 아래 데이터가 즉시 영구 삭제됩니다.

데이터 유형 처리 방식 삭제 시점
계정 정보 (UID, 닉네임) 영구 삭제 복구 불가 즉시
타로 리딩 기록 (고민, 카드, 결과) 영구 삭제 복구 불가 즉시
오늘의 카드 기록 영구 삭제 복구 불가 즉시

알림 설정 등 앱 설정 영구 삭제 즉시
결제 영수증 기록 보관 후 삭제 법적 보관 전자상거래법에 따라 5년 보관 후 파기

⚠️ 삭제된 계정과 데이터는 복구할 수 없습니다. 구독 중인 경우, 계정 삭제 전에 App Store 또는 Google Play에서 구독을 먼저 해지해 주세요. 계정을 삭제해도 스토어 구독은 자동으로 해지되지 않습니다.
