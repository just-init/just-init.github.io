1. 개인정보의 수집 항목 및 방법

아기이름연구소(이하 "앱")는 사용자의 개인정보를 최소한으로 수집하며, 다음과 같은 항목을 처리합니다.

구분 수집 항목 저장 위치
필수 Firebase 익명 인증 ID 서버 (Firebase)
선택 생년월일, 출생시간 (사주 분석용) 서버 (암호화 저장)
자동 수집 앱 충돌 로그, 기기 정보 서버 (Firebase Crashlytics)
광고 광고 식별자 (ADID/IDFA) 서버 (Google AdMob)

생년월일, 출생시간 등 민감한 정보는 암호화하여 서버에 저장됩니다.

2. 개인정보의 이용 목적

  • 이름 추천 및 사주 분석 서비스 제공
  • 앱 안정성 개선 (충돌 로그 분석)
  • 광고 서비스 제공 (무료 버전)
  • 인앱 구매 처리

3. 개인정보의 보유 및 파기

앱은 사용자의 개인정보를 목적 달성 후 즉시 파기합니다.

  • 로컬 데이터: 앱 삭제 시 자동으로 삭제됩니다.
  • Firebase 익명 인증 정보 및 서버 데이터: 이메일(justinit.service@gmail.com)로 삭제 요청 시 삭제됩니다.
  • 충돌 로그: 수집 후 90일 이내 자동 삭제됩니다.

4. 개인정보의 제3자 제공

앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다. 단, 다음의 경우는 예외로 합니다.

  • 법령에 의한 요청이 있는 경우
  • 사용자가 사전에 동의한 경우

5. 제3자 서비스

앱은 다음의 제3자 서비스를 이용합니다. 각 서비스의 개인정보 처리에 대해서는 해당 서비스의 개인정보처리방침을 참고하시기 바랍니다.

  • Firebase Authentication: 익명 인증
  • Firebase Crashlytics: 앱 충돌 분석
  • Google AdMob: 광고 제공 (무료 버전)
  • Apple App Store / Google Play Store: 인앱 구매 처리

6. 이용자의 권리

사용자는 언제든지 다음의 권리를 행사할 수 있습니다.

  • 개인정보 열람, 수정, 삭제 요청
  • 계정 및 데이터 삭제 요청
  • 광고 식별자 초기화 (기기 설정에서 가능)

계정 및 데이터 삭제를 원하시는 경우, justinit.service@gmail.com으로 삭제 요청 이메일을 보내주세요. 요청 확인 후 관련 데이터를 삭제해드립니다. 로컬에 저장된 데이터는 앱을 삭제하시면 함께 삭제됩니다.

7. 아동의 개인정보 보호

앱은 만 14세 미만 아동의 개인정보를 별도로 수집하지 않습니다. 앱의 주요 이용 대상은 출산 예정 부모 및 가족입니다.

8. 개인정보처리방침의 변경

본 방침이 변경되는 경우, 앱 내 공지 또는 본 페이지를 통해 변경 사항을 안내합니다.
