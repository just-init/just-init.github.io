스토어 배지 정본

App Store · Google Play 마크의 단일 출처. 이 파일은 배포되는 페이지가 아니라 복사해 쓰는 원본입니다.

왜 파일로 불러 쓰지 않고 복사해 쓰나 <img src="..."> 로 불러온 SVG 는 격리된 문서라 바깥 CSS 가 닿지 않습니다. currentColor 도 fill 도 먹지 않아, 밝은 배경(good-job)과 어두운 배경(내만트·unsubmitted)에 같은 파일을 쓸 수 없습니다. 그래서 마크업은 각 페이지에 인라인으로 두고 path 데이터만 이 파일을 정본으로 삼습니다. 색은 각 페이지 CSS 가 정합니다.

5. 지키는 규칙

  • path 데이터는 여기서만 고칩니다. 페이지에서 직접 손대면 다시 갈라집니다.
  • 클래스명 · 크기 · hover · 라벨 문구는 페이지 자유입니다. 통일 대상은 마크 모양뿐입니다.
  • 바깥 링크에는 target="_blank" rel="noopener" 를 붙입니다.
  • 고친 뒤에는 python3 scripts/check-store-badges.py 로 모든 페이지가 정본과 같은지 확인합니다.
